## Overview

TDR Limiter 6 is a modular mastering limiter comprising six independent processing stages—peak limiter, high-frequency limiter, clipper, and more—for transparent and controlled loudness maximization.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TDR Limiter 6** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Six Stages** | Peak limiter, HF limiter, clipper, gate, compressor, and output limiter |
| **True Peak** | ISP/true peak detection prevents digital overs on streaming platforms |
| **Stereo Modes** | Linked, mid/side, and dual-mono modes for different mastering scenarios |
| **GE Edition** | Full-featured Grand Edition available free via Tokyo Dawn Records |
